# Security Policy

## Sensitive data

Do not commit API keys, access tokens, private keys, client records, generated review packages, or private research inputs. Keep secrets in local environment configuration outside the repository.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories when available. Do not include live credentials, client data, or personal data in a public issue.

## Trust boundary

Generated briefs and source material are untrusted input. Review all output before execution or publication. The bundled HTML renderer is intentionally offline and permits only its fixed copy-to-clipboard script.
